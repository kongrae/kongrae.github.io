개인정보처리방침

도트 알람(iOS 앱) · 시행일 2026년 11월 12일

요약

도트 알람은 회원가입, 광고, 분석 도구가 없습니다. 알람과 쉬는 날, 근무 순서, 알람이 울리고 꺼진 기록은 이 iPhone 안에만 저장되며 개발자를 포함한 누구에게도 전송되지 않습니다. 앱이 인터넷으로 하는 일은 공휴일 자료를 내려받는 것 하나이고, 이때 이용자에 대한 정보는 보내지 않습니다(3항). 이용자가 직접 '문제 보내기'를 눌러 보낼 때만 앱 상태가 담긴 글이 개발자에게 전달됩니다(4항).

1. 앱이 사용하는 권한

권한목적
알람맞춰 둔 알람을 잠금 화면에서도 제시간에 울립니다.
알림(선택)내일 울려야 할 알람이 꺼져 있거나 내일이 쉬는 날일 때 정한 밤 시각에 알려 주고, 미리 맞춰 둔 알람 기간이 끝나 가면 알려 줍니다.
백그라운드 앱 새로 고침앱을 열지 않아도 알람 예약을 채우고 공휴일 자료를 확인합니다.

2. 기기 안에 저장되는 정보

항목목적보관
알람(시각, 이름, 반복, 알람음, 색, 다시 알림 등)알람 울리기, 목록과 달력 보여 주기앱 삭제 시 함께 삭제
쉬는 날, 날짜별 예외, 근무 순서그날 울릴 알람 정하기
공휴일 자료 사본인터넷이 없어도 공휴일에 쉬기
알람 기록(예정 시각, 끈 시각, 다시 알림을 누른 시각)알람이 제대로 울렸는지 확인하고 문제를 찾기. 30일이 지난 기록은 지웁니다
자기 전 확인 시각 등 설정설정 유지

이 정보는 기기 안에만 있으며 서버로 보내지 않습니다.

3. 공휴일 자료 내려받기

새로 지정된 공휴일을 반영하려고, 앱은 하루 한 번(앱을 열 때, 백그라운드 새로 고침 때, 설정에서 '지금 확인'을 누를 때) 공개된 공휴일 파일 holidays-kr.json을 내려받습니다. 이 파일은 한국천문연구원 특일 정보로 만들며 GitHub Pages에 있습니다.

요청에는 알람이나 쉬는 날 같은 이용자 정보가 들어가지 않습니다. 다만 다른 웹사이트에 접속할 때처럼, 파일을 내주는 GitHub(GitHub, Inc., 미국)의 서버에 IP 주소와 접속 시각 같은 접속 기록이 남을 수 있습니다. 이 기록은 GitHub 개인정보처리방침에 따라 처리되며, 개발자는 이 기록을 받거나 보지 않습니다.

4. 문제 보내기

이용자가 설정 › 문제 보내기를 누르면, 앱이 아래 내용을 담은 글을 만들어 메일 작성 화면(메일 계정이 없으면 공유 화면)을 엽니다. 이용자가 내용을 확인하고 직접 보낼 때만 개발자에게 전달되며, 누르지 않으면 아무것도 나가지 않습니다.

  • 앱 버전, 기기 모델, iOS 버전, 알람·알림 권한 상태
  • 알람 예약 수와 기간, 다음 알람, 공휴일 자료 버전과 마지막 확인 시각, 자기 전 확인 설정
  • 알람 목록(시각, 이름, 반복, 켜짐 여부, 알람음 등)과 최근 30일의 알람 기록

받은 내용과 보낸 메일 주소는 문의에 답하고 문제를 고치는 데만 쓰며, 처리가 끝나면 지웁니다.

5. 제3자 제공과 국외 이전

개인정보를 판매하거나 제3자에게 제공하지 않으며, 국외로 이전하지 않습니다. 3항의 접속 기록은 GitHub가 웹 서버 운영자로서 직접 처리합니다.

6. 아동의 개인정보

앱은 이름, 이메일, 전화번호, 위치 같은 개인정보를 받지 않으므로 나이와 관계없이 같은 방식으로 동작합니다.
